# Security policy

## Supported version

Only the latest commit on `main` is supported during the developer preview.

## Reporting a vulnerability

Please use GitHub private vulnerability reporting for this repository. Do not open a public issue for credential exposure, permission bypass, target substitution, unintended capture, unverified mutation, or recovery failure.

Include the affected macOS version and architecture, the smallest reproducible sequence, whether Accessibility or Screen Recording was granted, and any receipt or journal metadata that contains no private content. Do not attach screenshots, prompts, authentication files, raw context artifacts, or other user data unless a maintainer explicitly provides a safe channel.

The project will acknowledge a complete report as soon as practical, preserve confidentiality while validating it, and publish remediation details after a fix is available.
